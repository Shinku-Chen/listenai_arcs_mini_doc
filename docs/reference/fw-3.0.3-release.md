### ¶ Arcs-Mini 固件烧录教程(ADB工具)
本文给没有烧录经验的同学使用，目标是让你按步骤操作就能完成升级。
适用场景：
- 设备程序异常（例如上电就崩溃）
- 需要恢复出厂固件
- 需要升级到新版本固件
### ¶ 一、固件下载
可在文档《Arcs-Mini2 固件下载》 / 《Arcs-Mini3 固件下载》下载最新固件。
注意： Arcs-Mini2 和 Arcs-Mini3 固件不通用，切勿混淆。
### ¶ 区分 Arcs-Mini2 和 Arcs-Mini3 的方法
- 外观法
- ADB 命令判断法
Arcs-Mini3
Arcs-Mini2
3.0.3 版本及以上的固件会在状态栏直接显示设备类型。
- 参考文档《烧录工具安装教程》 安装 ADB 工具
- 打开终端，执行命令 adb devices -l 即可查看设备类型。
ADB 判断法需设备更新 3.0.3 版本及以上的固件。
### ¶ 二、开始前准备
- 安装烧录工具：参考文档 《烧录工具安装教程》
- 准备一根确认支持“数据传输”的 USB 线（不是只能充电的线）
- 电脑尽量使用主机后置 USB 接口，避免扩展坞/Hub
- 保证开发板供电稳定，烧录过程中不要断电/拔线
### ¶ 三、插线后电脑没有识别设备？按这个顺序排查
很多新手会卡在这一步，按下面顺序做，不要跳步：
- 换 USB 线
- 先换一根明确支持数据传输的线
- 换 USB 口
- 换到电脑另一个口，优先后置直连口
- 打开设备管理器确认是否有新设备 ADB Interface
- 重新插拔后再试一次
- 如果仍然没有任何设备变化
- 先重启电脑再试
- 继续失败请改用串口方式，查看 《串口烧录固件教程》
### ¶ 四、进入升级模式
- 按键进入
- cskburn desktop
- ADB命令
固件版本需要 2.0.0 版本及以上，此方式无法进入时，请尝试其他方式
接入USB后，按住功能键，然后复位即可
参考下图：
- Arcs-Mini3
- Arcs-Mini2
双击图标运行软件：
- 点击端口下拉框，选择 ADB 设备
- 点击 进入 Recovery 模式
- 如果失败，优先检查：USB 线 / USB 口 / 是否安装好工具驱动
选择 ADB 设备后点击 “进入 Recovery 模式”
可通过命令进入adb烧录模式:adb shell recovery
多次尝试仍无法进入 Recovery，请改用串口方式，查看 《串口烧录教程》

### ¶ 关于boot
通常情况下您不需要烧录boot固件，仅在特定版本更新时(2.3.0以下版本升级到2.3.0版本及以上)需要烧录boot固件。
-
确保已经进入 Recovery 模式
-
勾选boot.bin
-
打开终端，执行命令：
- adb shell "root;listenai;upgrade enter"
-
开始烧录
